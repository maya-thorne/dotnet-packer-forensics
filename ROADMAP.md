# Project Roadmap

This document tracks shipped capabilities and future engineering milestones for dotnet-packer-forensics.

---

## Shipped Capabilities

- [x] **Static PE Forensic Pipeline** — Entropy calculation, PE overlay inspection, baseline unpacker, and 7 unit tests.
- [x] **Costura Packer Unpacker Module** — Extraction and decompression of embedded .NET assembly resources via DeflateStream inversion, path traversal sanitization, and SHA-256 validation.
- [x] **ConfuserEx String Protection Decryptor & Resource Unpacker** — Automated decryption of protected constants (PRNG stream ciphers), encrypted resource containers, and CLI resource catalog extraction.
- [x] **PE Section & IAT Header Rebuilder** — Reconstruction of damaged PE headers, section table realignment, process memory dump unmapping, and CLR Cor20Header RVA recovery.
- [x] **SHA-256 Regression Test Harness & PE Integrity Verifier** — Bitwise byte-level comparison diagnostics, cryptographic hash digest verification (SHA-256/SHA-1/MD5), and deep PE/CLR structural integrity testing with 16 dedicated unit tests.
- [x] **.NET Reactor NecroBit & Native Stub Envelope Unpacker** — Native wrapper envelope stripping, token-keyed PRNG stream decryption of hidden CIL methods, Tiny/Fat CorILMethod format validation, .necro section reconstruction, and CLI automation.
- [x] **Eazfuscator.NET Bytecode VM Disassembler & De-virtualizer** — Heuristic VM opcode mapping, proprietary bytecode disassembly, AST-to-CIL translation, Tiny/Fat CorILMethod emission, .eazvm PE section synthesis, and automated directory extraction.
- [x] **Babel Obfuscator Cross-Assembly Symbol Demangler & Dependency Graph Restorer** — Unicode unprintable sanitization, interface method inference, getter/setter restoration, embedded BabelMap parsing, merged satellite assembly carving, and inter-assembly DAG generation (JSON, DOT, Mermaid) with 26 dedicated unit tests.
- [x] **ArmDot Method-Level Virtual Machine Opcode Emulator & De-virtualizer** — Heuristic VM opcode recovery, abstract evaluation stack emulation, multi-pass relative branch fixups, CorILMethod Tiny/Fat header emission, .armdot PE section injection, and automated directory extraction with 18 dedicated unit tests.
- [x] **IntelliLock Hardware Lock Defeat & License Envelope Neutralizer** — De-enveloping of encapsulated assemblies, LCG/XOR stream decryption, deterministic hardware fingerprint profiling and bypassing, synthetic perpetual master license (.lic) generation, Cor20Header EntryPoint restoration, and directory extraction with 22 dedicated unit tests.
- [x] **DeepSea Control Flow De-flattening & AST Reconstructor** — ECMA-335 CIL opcode disassembler, opaque predicate pruning, state-machine loop de-flattening, symbolic block flow resolution, multi-pass branch offset calculation, high-level AST and C# pseudocode recovery, .deepsea PE section synthesis, and automated directory extraction with 17 dedicated unit tests.
- [x] **CLI Metadata Anti-Tamper Heuristics & In-Memory JIT Dumper Engine** — ECMA-335 CorILMethod Tiny/Fat header parser and serializer, PRNG/LCG stream cipher decryption with cryptographic buffer zeroizing, JIT dumper ingestion interface supporting in-memory scans, structured JSON descriptors, and binary JITD streams, static anti-tamper detection across corrupted `#~`/`#-` tables, PE `.antitamper` section injection, and safe directory extraction with 26 dedicated unit tests.
- [x] **Anti-Dump Process Memory PE Header Healer & Scylla Dump Normalizer** — Heuristic detection and classification of anti-dump corruptions, Scylla process memory dump unmapping (aligning virtual addresses to file offsets), BSJB CLR metadata scanning, ECMA-335 Cor20Header recovery and synthesis, standard mscoree.dll CLR import table (IAT) reconstruction, section table name sanitization and synthesis, and safe directory extraction with 16 dedicated unit tests.
- [x] **Native Multi-Architecture Resource Demuxer & Platform Router** — Static identification, carving, and decompression of multiplexed native PE/ELF/Mach-O binaries (x86, x64, ARM64, ARM, IA64) across manifest resources, directory structures, and PE sections. Includes automated architecture spoofing and mismatch detection, realistic runtime loader routing simulation (WoW64 compatibility, Windows on ARM x64/x86 emulation, macOS Rosetta 2 translation), memory buffer wiping via ctypes zeroization, and safe architecture-partitioned directory extraction with 14 dedicated unit tests (243 total suite tests).
- [x] **Automated .NET Threat Hunting YARA & Sigma Signature Rule Synthesizer** — Dynamic synthesis of production-ready YARA v4+ detection rules (with `import "pe"` and `import "math"` conditions, PE/CLR structural attributes, CIL opcode patterns, protector markers) and Sigma v2 YAML rules (process creation, file drop, and CLR image load telemetry). Supports Specific, Behavioral, and Threat Hunting tiers, deterministic UUID v5 generation, memory zeroization, safe directory export, and CLI automation with 13 dedicated unit tests (256 total suite tests).
- [x] **Native Mixed-Mode PE Static Analyzer & CIL-Native Transition Tracer** — Static detection and structural decomposition of mixed-mode (IJWH / C++/CLI) PE binaries, IMAGE_COR_VTABLEFIXUP table and slot width resolution (32/64-bit), native TLS callbacks and entry point tracing, unmanaged export thunks and P/Invoke boundary mapping, composite threat risk scoring, memory buffer zeroization via ctypes, and safe directory extraction with 12 dedicated unit tests (268 total suite tests).
- [x] **CIL Control Flow Graph (CFG) Generator & High-Entropy Block Visualizer** — Comprehensive ECMA-335 CIL opcode disassembler supporting 1-byte, 2-byte, branch, and switch table decodings. Constructs basic block topology, links directed fallthrough and branch transitions, calculates McCabe cyclomatic complexity via decision point analysis, detects natural loops and back-edges, profiles Shannon entropy across bytecode basic blocks to isolate encrypted payloads or obfuscated stubs, and exports publication-grade visual flowcharts across Mermaid, Graphviz DOT, self-contained valid XML SVG vector graphics, and terminal ASCII diagrams with 19 dedicated unit tests (287 total suite tests).
- [x] **WPF BAML & Embedded UI Resource Decompiler & XML Restorer** — Full-stack MS-BAML binary record parser and XAML reconstructor. Decodes 7-bit length-prefixed variables, tokenized record streams, and built-in WPF known types and dependency properties. Extracts embedded `.baml` streams from standard managed `.resources` containers (0xBEEFCACE) and raw PE sections. Performs automated static forensic anomaly detection across suspicious event handler bindings, concealed clandestine UI controls (`Visibility="Collapsed"` with active payloads), external C2 URIs, and high-entropy Base64 blobs. Emits well-formed XML with attribute escaping and namespace declarations, and supports safe directory export with 11 dedicated unit tests (298 total suite tests).
- [x] **Deobfuscation Regression Fuzzing Harness & Synthetic Mutated Binary Generator** — End-to-end sandboxed stress-testing fuzzing engine and synthetic PE/.NET baseline generator. Emits structurally valid PE32 assemblies and mutates across 11 targeted architectural strategies (bit flips, byte noise, DOS/NT/Optional headers, section table anomalies, Cor20 COM descriptors, BSJB metadata stream headers, CIL instruction opcodes, overlay slack injection, and boundary truncation). Features sandboxed target execution across all forensic pipelines with crash classification (clean pass, handled error, regression crash, timeout hang, resource exhaustion), timeout safety guards, crash reproduction artifact bundles, and persistent JSON RegressionLedger with 42 dedicated unit tests (340 total suite tests).
- [x] **Batch Forensic Automation CLI Engine & Multi-Threaded PE Directory Scanner** — High-throughput parallel static forensic scanning across directories of PE and .NET binaries. Features fast MZ/PE\\0\\0 header pre-filtering, configurable multi-threaded ThreadPoolExecutor worker pool with thread-safe progress callbacks, per-file execution timeout bounds, recursive directory discovery, glob pattern matching, and file size thresholds. Integrated multi-format reporting with structured terminal console tables, CSV exports, complete JSON manifests, and self-contained offline HTML dashboards (zero external CDN dependencies, strict HTML entity escaping, dark-mode cybersecurity theme, and interactive client-side search/filtering) with 41 dedicated unit tests (381 total suite tests).
- [x] **Native AOT & ReadyToRun (R2R) Composite PE Forensic Disassembler & Symbol Parser** — Ahead-of-time (AOT) forensic decomposition and symbol recovery engine for .NET 7, .NET 8, and .NET 9 precompiled binaries. Features complete parsing of ReadyToRun headers and section tables (COMPILER_IDENTIFIER, RUNTIME_FUNCTIONS, METHODDEF_ENTRYPOINTS, IMPORT_SECTIONS), identification of Redhawk (Rhp*) runtime helper call sites, automatic .NET generation inference, symbol demangling of C-style mangled descriptors, standalone x64/x86 native machine code disassembly with branch target resolution, basic block partitioning, and safe artifact directory export with 20 dedicated unit tests (401 total suite tests).
- [x] **Kernel Memory Dump Carving & Residual CIL Metadata Reconstructor** — Forensic analysis and carving engine for Windows Minidumps (MDMP), kernel crash dumps, and abnormal process termination memory snapshots. Features deep parsing of 32/64-bit memory list streams and loaded module catalogs, ECMA-335 BSJB metadata root scanning (`0x424A5342`), string heap extraction (`#US` user string literals and `#Strings` identifiers), `#~` metadata table row count and valid mask recovery, residual CIL method body recovery (validating Tiny and Fat header structures, CIL opcode sequences, and method termination invariants), virtual memory layout unmapping to disk alignment, minimal compliant PE32/CLR container synthesization around orphaned metadata heaps, and safe artifact export with 16 dedicated unit tests (417 total suite tests).
- [x] **Ghidra & IDA Pro Python Automated Headless Bridge & Symbol Synchronizer** — Bidirectional decompiler bridge generating headless Python scripts and batch runners (`.bat`/`.sh`) for Ghidra FlatProgramAPI (Python 3/Jython), IDA Pro 7.x-9.x (IDAPython), and Radare2/Cutter (`.r2`). Features dynamic imagebase rebasing, safe identifier labeling, and multi-subsystem forensic synchronization correlating PE headers, Cor20 COM descriptors, .NET Reactor NecroBit methods, Eazfuscator/ArmDot VM containers, Babel demangled symbols, mixed-mode VTFixup/TLS transitions, Native AOT Redhawk (Rhp*) helpers, kernel memory dump carved methods, and CFG high-entropy anomaly blocks. Includes conflict resolution, confidence filtering, and directory export (scripts, symbols CSV/JSON, comments, bookmarks, telemetry) with 21 dedicated unit tests (438 total suite tests).
- [x] **Multi-Engine Binary Diffing & AST Flow Graph Comparator** — Structural and semantic binary comparison pipeline measuring PE/CLR metadata divergence, section alignment/entropy shifts, injected protector sections (`.necro`, `.eazvm`, `.armdot`, `.tamper`), CIL instruction sequence edit distance (Jaccard multiset, normalized Levenshtein, 3-gram Sørensen-Dice), Control Flow Graph (CFG) basic block signature matching, McCabe cyclomatic complexity deltas, control flow flattening state dispatchers, and statement-level AST flow graph topology. Includes self-contained interactive offline dark-themed HTML visual diff dashboards, multi-format safe directory export (JSON, CSV, HTML, TXT), and CLI integration with 18 dedicated unit tests (456 total suite tests).
- [x] **CLR JIT Compilation Tracing & Bytecode Capture Harness** — Emulation-based dynamic extraction and tracing engine for obfuscators relying on native CLR runtime JIT hooks (`ICorJitCompiler::compileMethod`). Features static detection of JIT export/import detours, known protector signatures (ConfuserEx AntiTamper, .NET Reactor NecroBit, ILProtector, ArmDot, Eazfuscator), virtual JIT compiler emulation for CorILMethod Tiny/Fat decoding and LCG/XOR PRNG stream decryption, multi-format trace log ingestion (JSON, CSV, binary JITD, regex debugger logs), recovered bytecode injection into PE `.jitcapt` section and compliant minimal PE32 wrapper container synthesis, CIL disassembly generation, and safe directory export with 19 dedicated unit tests (475 total suite tests).
